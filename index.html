Abstract

Video object detection is a pivotal yet challenging task in computer vision. Recent DETR-based methods have achieved promising performance but still suffer from frame-agnostic object query initialization, scale-agnostic attention mechanism, and heterogeneity-agnostic feature transformation.

To address these limitations, we propose M2TDiff, a Multi-scale MoE-enhanced Transformer Diffusion Network for video object detection.

First, we introduce a reinforcement-guided diffusion query generator, which models object query distribution through an iterative diffusion process and generates adaptive, content-aware object queries.

Second, we design a multi-scale graph interaction transformer encoder that combines attention mechanisms with dynamic graph convolutions for scale-aware feature learning.

Third, we develop a sparsely-gated mixture-of-experts transformer decoder, dynamically routing heterogeneous object queries to specialized experts.

Furthermore, we introduce two variants: M2TDiff++ for higher accuracy and M2TDiff-Fast for efficient inference.

Method

Reinforcement-Guided Diffusion Query Generator. Generates adaptive object queries through diffusion modeling with multi-trajectory reinforcement learning.

Multi-Scale Graph Interaction Transformer Encoder. Learns scale-aware representations by integrating attention and dynamic graph interaction.

Sparsely-Gated MoE Transformer Decoder. Routes heterogeneous queries to specialized experts for query-specific representation learning.

Variants

M2TDiff++

Higher Accuracy Variant

M2TDiff++ further improves detection accuracy by exploring more diverse spatial-temporal cues and enhancing object query generation with improved temporal information aggregation.

M2TDiff-Fast

Efficient Inference Variant

M2TDiff-Fast accelerates inference through an optimized keyframe/non-keyframe processing strategy while maintaining competitive detection performance.

Requirements

The code is tested with the following environment:

  • Linux, CUDA >= 11.0, GCC >= 5.4
  • Python >= 3.8

We recommend using Anaconda to create a conda environment: 


conda create -n M2TDiff python=3.8 pip

conda activate M2TDiff

Install PyTorch and torchvision according to your CUDA version. For example: 


conda install pytorch torchvision 
-c pytorch

Install other dependencies: 


pip install -r requirements.txt

Build MultiScaleDeformableAttention: 


cd ./models/ops

sh ./make.sh

Training

We use ResNet-50 and ResNet-101 as backbone networks. The following commands are used to train M2TDiff.

Training on single node: 



# Train M2TDiff with ResNet-50 backbone


GPUS_PER_NODE=8 \
./tools/run_dist_launch.sh \
$1 r50 $2 configs/r50_train_m2tdiff.sh





# Train M2TDiff with ResNet-101 backbone


GPUS_PER_NODE=8 \
./tools/run_dist_launch.sh \
$1 r101 $2 configs/r101_train_m2tdiff.sh

Training on Slurm cluster: 



GPUS_PER_NODE=8 \
./tools/run_dist_slurm.sh \
<partition> r101 8 \
configs/r101_train_m2tdiff.sh
